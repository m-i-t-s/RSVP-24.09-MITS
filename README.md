# RSVP — Coordenadas Improváveis

Esta versão usa o layout do PDF de referência como base visual, para a homepage ficar fiel ao desenho aprovado.

## Atualizar no GitHub
Substitua no repositório:
- `index.html`
- `style.css`
- `script.js`
- `apps-script.gs`
- pasta `assets`

Faça **Commit changes**. O GitHub Pages publica a nova versão automaticamente.

## Funcionamento
- Nome obrigatório
- Telefone opcional
- Email opcional
- Botões SIM / NÃO clicáveis exatamente sobre o layout
- No celular, o formulário mantém a mesma composição e o convite aparece logo abaixo

## Google Sheets
Para registrar respostas, configure `apps-script.gs` e cole a URL `/exec` gerada em `script.js`.
